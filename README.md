## 📖 Overview

**System Extractor** is a lightweight, high-performance Node.js and Express-based diagnostic engine designed to run seamlessly on mobile environments via Termux. It extracts deep operational telemetry, resource metrics, runtime versions, and workspace file structures, presenting them instantly through a sleek hacker-styled web dashboard.

---

## ✨ Key Benefits

* **Real-Time Telemetry:** Instantly monitors CPU architecture, core counts, total/free memory usage, and system uptime.
* **Runtime Diagnostics:** Automatically validates and extracts exact version numbers for Node.js, npm, and Git.
* **Workspace Transparency:** Scans and indexes project directory contents instantly for rapid auditing.
* **Mobile-First Architecture:** Engineered to run smoothly on Android via Termux with zero heavy cloud dependencies.
* **Clean Web Interface:** Features a responsive, dark-mode dashboard optimized for quick, one-click execution.
